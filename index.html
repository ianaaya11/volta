Volta

A circuit you can watch working.

Volta is a live analog and digital circuit simulator that runs entirely in your browser. Draw a schematic, press Run, and the circuit comes alive: current flows as moving dots along the wires, wires take colour from their node voltage, capacitors show which way they are charged, LEDs light, motors spin up against their own back-EMF, and a built-in oscilloscope traces any node you point at.

It is not a picture of a circuit. Underneath is a real solver — modified nodal analysis with Newton–Raphson for the non-linear parts — the same method the industry-standard tools use. You can open the Math panel and read the equations it built, the matrix it assembled, and how the iteration converged.

Everything in one place

Around fifty parts: sources, passives, diodes and transistors, op-amps, relays and motors, logic gates, latches and flip-flops, a counter, a 7-segment display, a 555 timer, converters, and voltmeters, ammeters, ohmmeters and wattmeters that read live on the schematic.

Answers, not just pictures

Transient simulation, AC sweeps with Bode plots, an oscilloscope, and a math view that shows the solver's own working so the result is something you can check rather than something you must trust.

Code that drives the circuit

Write an Arduino-style sketch and run it against the live schematic in simulated time — pinMode, digitalWrite, digitalRead, delay — and watch the hardware respond.

Ask in plain language

Describe a circuit and have it built for you, or ask why the one on screen is not behaving. The assistant reads the schematic you are looking at.

Works anywhere, offline

An installable web app with no server behind it. It runs on a laptop, a phone, or a school machine with a slow connection, and it keeps working when the connection goes away entirely.

Software / ML Engineer

I build tools that make hard things legible. Volta came out of wanting a circuit simulator that shows you what is happening rather than just what the answer is — one that runs on whatever device a student already owns, needs no licence, no install and no reliable internet connection, and is honest enough to show its own working when you ask.

The commons is the other half of the idea: circuits are easier to learn from when you can open someone else's, take it apart, and put it back together differently.

MCU code

Runs against the live circuit in simulated time. Place MCU pin parts on the schematic and address them by number. Supported: setup loop pinMode digitalWrite digitalRead delay millis, plus int/float, if, while and for.

Circuit assistant

Paste an Anthropic API key to enable the assistant. It is stored in this browser's local storage and sent only to api.anthropic.com — which means any script running on this page could read it. Use a key you're comfortable with that, and revoke it if you share this device.
